What MLOps means here

Picture a relay with three lanes: develop, ppe, and prod. The baton is the git commit — the code — and each lane runs the same race, then writes its own result.

You do not hand a finished trophy from one lane to the next. Databricks names that rule: deploy code, not models.

In this repo that manifest is a DAB. The bundle is databricks.yml plus the YAML it includes.

The only resources deploy creates.

🏷️
databricks/targets/*.yml

One target each for develop, ppe, and prod.

One bundle, every environment

Do not make a bundle per environment. Do not split the environments into three repos.

What the include list leaves out

This block in databricks.yml is the permission slip for the manifest.

CODE 
include:
  # Serving endpoint stays in databricks/artifacts/ but is applied by CD via
  # `serving-endpoints create --no-wait`. Putting it in the bundle made
  # `bundle deploy` wait on container creation and blocked the job run.
  # Only the train-then-infer pipeline is deployed. Standalone train and
  # infer jobs never ran, so they are not in this bundle.
  - databricks/jobs/*.yml
  - databricks/targets/*.yml
PLAIN ENGLISH

The include list. Anything not named here stays outside the manifest.

The endpoint YAML is not in the include list. CD applies that file later.

serving-endpoints create --no-wait does the applying. It does not sit inside bundle deploy.

Bundle deploy must not wait on a serving container. That wait blocked the job run.

Only the job pipeline is in the bundle.

Jobs that never ran on their own stay off this list.

The job files are included. Deploy creates those jobs.

The target files are included. One manifest still names every environment.

Stick the spine labels

A run logs its tags, and registration then points the environment alias and Champion at the new version. These two functions are the real code in notebooks/train_register.py.

CODE 
def aliases_for_env(alias: str) -> tuple[str, ...]:    """Env alias plus Champion, de-duplicated. Empty alias yields Champion only."""    labels: list[str] = []    if alias:        labels.append(alias)    if "Champion" not in labels:        labels.append("Champion")    return tuple(labels)  def set_model_aliases(name: str, version: str, alias: str) -> tuple[str, ...]:    """Point the env alias and Champion at the registered version."""    client = mlflow.MlflowClient()    applied = aliases_for_env(alias)    for label in applied:        client.set_registered_model_alias(name, label, version)        print(f"aliased {name}@{label} -> version {version}")    return applied
