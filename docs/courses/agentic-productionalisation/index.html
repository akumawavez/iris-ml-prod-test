Lookup, do not grow

src/iris_model/score.py Loads the album. Does not fit a new model.
CODE 
def score_model(model_path: Path, rows: list[dict]) -> list[dict]:
    """Score each row with the saved Pyfunc. Do not fit a model here."""
    validate_rows(rows)
    loaded = mlflow.pyfunc.load_model(str(model_path))
    frame = pd.DataFrame(rows).loc[:, list(FEATURES)]
    raw = loaded.predict(frame)
    if isinstance(raw, pd.DataFrame):
        raw = raw.to_dict(orient="records")
    return list(raw)
PLAIN ENGLISH

score_model takes the path to the album and the rows of measurements, then promises a list of names back.

The gate reads the ticket

This check lives in .github/workflows/cd.yml, in YAML. Under each run, a shell command guards the gate.

CODE 
      - name: Refuse unless explicitly confirmed
        run: |
          test "${{ inputs.confirm }}" = "YES"
      - name: Match git branch to Databricks target
        run: |
          case "${{ inputs.target }}" in
            develop) expected=develop ;;
            ppe) expected=ppe ;;
            prod) expected=main ;;
            *) echo "unknown target ${{ inputs.target }}" >&2; exit 1 ;;
          esac
          test "${GITHUB_REF_NAME}" = "$expected"
PLAIN ENGLISH
