The ticket, line by line

This YAML is exact, from databricks/artifacts/iris_endpoint.yml. The comments stay in the code.

CODE 
        served_entities:
          - name: iris_species
            entity_name: ${var.registered_model_name}
            # Shape reference only. CD does not deploy this file.
            # scripts/apply_served_version.py sets entity_version from the alias.
            entity_version: ${var.model_version}
            workload_type: CPU
            workload_size: Small
            scale_to_zero_enabled: true
PLAIN ENGLISH

The list of coats this window is allowed to hand back.

One served entity. On the endpoint its name is iris_species.

entity_name is the Unity Catalog model. A bundle variable fills in the name.

This comment stays. The file is a shape reference only. CD does not deploy this file.

This comment stays too. scripts/apply_served_version.py sets the served version from the alias.

entity_version is the pin. The bundle variable model_version defaults to "5".

The workload type is CPU, an ordinary chip.

The workload size is Small.

Scale-to-zero is on, so an idle window can close.

🎟️
Do not follow latest

Moving the pin is a reviewed change, and the version must already exist in that environment’s registry.

Why the window sits outside the bundle

The coat check is written down. Bundle deploy does not build the window.

1
Deploy waited on the container

Putting the endpoint in bundle deploy made deploy wait while the container was created.

2
The job could not run

That wait blocked the job run. The batch work sat behind a door that was still being built.

3
include lists only jobs and targets

So include lists only jobs and targets.

4
Create without waiting

When spend is approved, CD creates the endpoint with serving-endpoints create --no-wait.

5
No inference-table capture

There is no inference-table capture in this file.

6
Payload logging stays off

Payload logging is a separate bill. Leave it off until the cost sheet lists it.

What an idle hour costs

The bill follows whether the window is open. A shut window and a warm window are different meters.

🧥

Idle, scale-to-zero

About $0 per hour. Nobody is at the window, so it can close.

🔥

Warm Small CPU

About 4 DBU per hour while the window is open.

4️⃣

Four slots

Small allows 4 concurrent slots, about 1 DBU per hour each.

✋

One request resets the timer

A live request resets the idle timer. Do not POST the endpoint while studying.

Tags on the endpoint tie the bill to the YAML.

project Which project this window belongs to
env Which environment: develop, ppe, or prod
alias The label the script read when it wrote the pin
managed-by dab The bundle family this description belongs to
owner Who owns the bill
