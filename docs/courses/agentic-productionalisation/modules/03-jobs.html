Jobs — Week 1, day 3 of 3

Week 1, day 3 of 3. The second car leaves only if the engine does.

If the engine does not leave

Picture a two-car train. The second car is coupled to the first. If the engine does not leave, the second car stays in the station.

🚂

Engine car

The task named train. It has to leave first.

🔗

The coupling

depends_on is the coupler. Infer waits on train.

🚃

Second car

The task named infer. It stays in the station when train fails.

In this repo that timetable is one Lakeflow job per environment key.

iris_ml_job_pipeline.yml The one timetable. Path: databricks/jobs/iris_ml_job_pipeline.yml.
iris-ml-job-pipeline-${var.env_suffix} Deployed name. develop, ppe, and prod can share one workspace.

The coupling, line by line

The second car is a spark_python_task. These lines are the real coupler, copied from the job file.

CODE 
        - task_key: infer
          depends_on:
            - task_key: train
          spark_python_task:
            python_file: ../../notebooks/infer.py
            parameters:
              - --model-uri
              - models:/${var.registered_model_name}@${var.model_alias}
PLAIN ENGLISH

Name this car infer. It is the second task on the job.

Couple it. It is not allowed to leave on its own.

The car it waits for is train. If that engine does not leave, infer stays.

The work is a Python file the job runs for you.

That file is notebooks/infer.py, two folders up from the job file.

Hand the file a short list of instructions.

The first instruction names which model to load.

Load the named model at the current alias, the nameplate train moves when it succeeds.

One timetable, one file

One job definition is one file. Do not split a job key across includes.

No engine left idling

The cars do not sit in the station with the motor running. Compute starts for the task and stops when the task ends.

⚡

Serverless

Serverless is the practice. No all-purpose cluster is in the bundle.

What each car is told

Train files the model and moves the nameplate. Infer only loads that nameplate. Neither car has its own timetable.

🚂

Train

Runs notebooks/train_register.py with flags --register, --alias ${var.model_alias}, and --registered-name ${var.registered_model_name}. Tracking uri is databricks.

🚃

Infer

Runs notebooks/infer.py. Model URI is models:/${var.registered_model_name}@${var.model_alias}.
