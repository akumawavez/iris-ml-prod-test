The settings, line by line

This YAML is exact, from databricks/artifacts/iris_endpoint.yml. Creating the live light is still a later, human-gated step.

CODE 
        served_entities:
          - name: iris_species
            entity_name: ${var.registered_model_name}
            entity_version: ${var.model_version}
            workload_type: CPU
            workload_size: Small
            scale_to_zero_enabled: true
PLAIN ENGLISH

The list of models this porch light is allowed to serve.

One served copy. On the endpoint its name is iris_species.

Which registered model, filled from a variable, so each environment can name its own.

Serve this version pin, also from a variable, so the light stays on a page you chose.

Use a CPU. This flower model belongs on that everyday chip.

Use the Small size. That is the machine written for this little model.

Scale-to-zero is on. When the path is empty, the computers turn off.

The pin’s default is exact, from databricks.yml.

CODE 
  model_version:
    description: Served UC model version. Bump after a new version is registered.
    default: "5"
PLAIN ENGLISH

The setting that chooses which version the light serves.

A note for people: this is the served Unity Catalog model version. Raise the number after a new version is registered.

Until someone sets another number, the pin is the text 5. That is a fixed page, not an alias such as latest.

💡
Idle is the cheap state

Scale-to-zero is not free while someone is calling it. A warm Small CPU endpoint is about 4 DBU per hour. Idle is the cheap state, and a request resets the idle timer.
