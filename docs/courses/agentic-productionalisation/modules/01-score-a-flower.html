Lookup, do not grow

The first finished thing in this repo is a saved model you score on your own machine.

A pytest check loads that album. It does not fit a new model.

src/iris_model/score.py Loads the album. Does not fit a new model.
CODE 
def score_model(model_path: Path, rows: list[dict]) -> list[dict]:
    """Score each row with the saved Pyfunc. Do not fit a model here."""
    validate_rows(rows)
    loaded = mlflow.pyfunc.load_model(str(model_path))
    frame = pd.DataFrame(rows).loc[:, list(FEATURES)]
    raw = loaded.predict(frame)
    if isinstance(raw, pd.DataFrame):
        raw = raw.to_dict(orient="records")
    return list(raw)
PLAIN ENGLISH

score_model takes the path to the album and the rows of measurements, then promises a list of names back.

The inner note says to use the saved Pyfunc, because fitting here would press a new flower over the old labels.

Check the row first so a torn or half-empty specimen never gets a guess.

MLflow opens the album folder from the path you gave it.

Each feature the album was pressed with is kept, and extra fields are dropped so they cannot nudge the name.

Asking the saved model for a species is a lookup. The album itself does not change.

If the answer arrives as a table, it becomes a plain list the command can hand back.

That list is returned, and the pressed album stays as it was.

Four numbers, then the name

Each measurement is a required flag. The score command is a CLI, so a missing number stops you before any guess.

src/iris_model/score.py The four measurements the command requires.
CODE 
    parser.add_argument("--model", default="models/iris_species")    parser.add_argument("--sepal-length-cm", type=float, required=True)    parser.add_argument("--sepal-width-cm", type=float, required=True)    parser.add_argument("--petal-length-cm", type=float, required=True)    parser.add_argument("--petal-width-cm", type=float, required=True)
PLAIN ENGLISH

The model flag points at the album, and if you skip it the command still opens models/iris_species.

Sepal length has to be typed, because a missing length means the specimen is not ready to match.

Sepal width is required for the same reason: the album was pressed with all four sides filled in.

Petal length is required so the command cannot guess from a partial flower.

Petal width finishes the set. These four flags are the only measurements the album knows.

The last stop adds a plain-language narrative and a SHAP calculation story. SHAP is one explanation style, and this page does not teach the math.
