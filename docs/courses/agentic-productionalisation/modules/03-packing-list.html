Tape the list to the door

A house move starts with a checklist taped to the door. Boxes are labeled before the van arrives. You do not invent a new box system on the driveway.

Productionalisation here is that checklist. This git repo already holds the code, the tests, the bundle, and the documents a new owner can follow.

One label for every box

Training and scoring share one schema. A new column is a contract change, so both sides move together.

src/iris_model/schema.py

Code 
"""Feature names and the exact scoring error sentences.""" FEATURES = (    "sepal_length_cm",    "sepal_width_cm",    "petal_length_cm",    "petal_width_cm",)
Plain English

A note to the next reader: these names are the measurements, and the error sentences scoring shows must use them exactly.

A blank line, so the note and the list stay easy to tell apart.

The shared list starts here. Training and scoring both read it. The parentheses mark the group as fixed.

How long the sepal is, in centimeters.

How wide the sepal is, in centimeters.

How long the petal is, in centimeters.

How wide the petal is, in centimeters.

The list closes. Add a name here only when the contract should change for training and scoring together.
